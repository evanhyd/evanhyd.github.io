About This Blog

Welcome to my digital garden! This site hosts articles, snippets, and deep-dives on Modern C++, algorithms, and systems engineering.

✨ How Automatic Article Publishing Works

Adding new articles is completely frictionless:

  1. Add a Markdown file in the articles/ directory (e.g. articles/my-new-post.md or a subfolder like articles/my-topic/README.md).
  2. (Optional) Add frontmatter at the top of your markdown file: 
    ---
title: My Cool Algorithm
date: 2026-11-01
tags: ["C++", "Algorithms"]
summary: Quick explanation of how this works.
---
    If you omit frontmatter, the site automatically uses your first # Heading as the title and computes the summary and reading time automatically!
  3. Git commit and push to GitHub: 
    git add .
git commit -m "Add new article: My Cool Algorithm"
git push
  4. GitHub Actions does the rest! The automated workflow rebuilds articles.json and deploys your updated blog to GitHub Pages immediately.
💡 Local Offline Preview: Run npm run dev or node build-index.js to test locally anytime!
